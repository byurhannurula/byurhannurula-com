## Code

```ts title="src/lib/drafts.ts"
// keep every draft, even when a new note starts
export async function saveDraft(text: string) {
  const id = crypto.randomUUID();
  await store.set(id, { text, savedAt: Date.now() });
  return id;
}
```

## Do and do not, pros and cons

<Do>

- One idea per post.
- Publish rough.

</Do>
<Dont>

- Wait for the perfect draft.
- Start with an ultimate guide.

</Dont>
</DoDont>

<ProsCons>
<Pros>

- Files in the repo, no service to run.
- Components where plain text is not enough.

</Pros>
<Cons>

- No editor on a phone.
- A build for each typo.

</Cons>
</ProsCons>
