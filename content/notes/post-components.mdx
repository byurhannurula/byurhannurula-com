A key in a sentence: press <Kbd>Cmd</Kbd> <Kbd>K</Kbd> to open the menu and <Kbd>Esc</Kbd> to close it.

<Aside>
  A side note. It sits in the margin on a wide screen and in the text on a small
  one.
</Aside>

A side note belongs to the paragraph after it. It holds the detail that is good to know but would break the line of thought: a source, a number, a small story.

A footnote is the other way to add a detail.[^1] It keeps a number in the text and the note at the end of the page. With the footnotes option set to the margin, a wide screen shows each note next to its line.[^2]

[^1]: Write it in Markdown: a `[^1]` mark in the text and a `[^1]:` line anywhere in the file.

[^2]: The notes stack from the top, so two notes close together do not cover each other.

## Steps

  </Step>
  <Step title="Add the front matter">

  </Step>
  <Step title="Push">The build makes the page. There is no step four.</Step>
</Steps>

## File tree

A code block with the language `tree` becomes a file tree. Two spaces per level.

```tree

src/
  components/
    mdx/
      figure.tsx
      steps.tsx
  lib/
    mdx.tsx  # turns a note into a page
package.json
```

  await store.set(id, { text, savedAt: Date.now() });
